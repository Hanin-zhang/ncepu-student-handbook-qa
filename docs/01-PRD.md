## 2. 产品概述

### 2.1 一句话定位

面向华电学生的 **7×24 小时在线「校园百事通」**：把《学生手册》、教务管理规定、办事指南等制度文件构建为结构化知识库，学生用自然语言提问即可获得**带条款出处的答案**，不需要翻阅长篇手册。
【源：课题摘录 §1】

### 2.2 目标用户

| 用户群 | 说明 | 来源 |
|---|---|---|
| 学生（普通用户） | 主要使用者，提问并阅读带引用的答案、查看自己的历史咨询记录 | 【源：课题摘录 §1、§2；技术文档 §4.4「普通用户」】 |
| 管理员 | 管理知识文档、查看问答日志、配置违禁词表 | 【源：课题摘录 §2 系统管理模块；技术文档 §4.4「管理员」】 |
| 审核员 | 对 AI 生成草稿进行人工审核（**二期能力**） | 【源：技术文档 §4.4「审核员」；课题摘录 §2（二审期归属见 00 号文档 C-10）】 |
| 教师 | 无教师这一角色| 已确认 见 Q-05 |

### 2.3 核心价值

**答案可溯源。** 系统不只给结论，还给「引自哪份文件的哪一章哪一条」，让学生能自行核对，把「AI 说什么就是什么」变成「AI 指出原文在哪里」。【源：课题摘录 §1、§5.1】

辅以两点：**边界可控**（只答校园制度，无关问题统一拒绝/引导，抑制幻觉）【源：课题摘录 §5.2】；**内容可维护**（管理员上传 Markdown 即完成入库，无需重建全库）【源：技术文档 §5.2】。

### 2.4 成功度量

> 只使用文档能支撑的度量。文档未给量化指标的，一律标 `【待确认】`，不编造数字。

| 编号 | 度量 | 目标值 | 来源 |
|---|---|---|---|

| M-02 | 一期 5 项任务可演示 | 全部可端到端演示（gRPC 通信 / 基础 RAG / Java 业务闭环 / 部署与安全 / 可选增强） | 【源：技术文档 §14.1】 |
| M-03 | 端到端流式链路可演示 | 可实际展示「跨语言 RPC、Protobuf 定义、gRPC 流式响应、Java SSE 到前端流式推送、RAG 流程」 | 【源：技术文档 §8】 |

### 3.3 权限实现约束

- 接口级/角色级权限由 Spring Security 最小化配置承载（stateless JWT + BCrypt + 路由/方法级角色控制）【源：技术文档 §1.1、§4.4】。
- **文档级 ACL 不由 Spring Security 自动解决**，需在 Service 层实现；`UD-07` 已定：**一期不做 ACL 过滤**，`permission` 字段仅落库占位，二期启用（NFR-20）【源：技术文档 §4.4】【UD-07】。
- 未认证返回 401、越权返回 403【源：技术文档 §4.4】。
